# Docash — Release notes

## 2026-10-10 · 1.0 (versionCode 1)

### Incluido

- Rediseño visual de Inicio, Movimientos, Plan y Recurrentes con navegación consistente.
- Registro de gastos e ingresos usando el teclado nativo de Android.
- `Actionsheet` de Gluestack para categorías, repetición, rachas y alta de recurrentes.
- Backdrop, sombras, arrastre y transiciones más consistentes en hojas modales.
- Selector de gasto/ingreso con identidad visual roja y verde.
- Presupuestos, movimientos recurrentes y datos demo para visualizar meses completos.
- Sistema de rachas con revisiones diarias, descansos, hitos y recordatorios.
- Soporte bilingüe español/inglés y respaldo de los nuevos datos de rachas.

### APK

- Build entregado: `debug`.
- Arquitectura: `arm64-v8a` (compatible con Galaxy S22).
- Esta compilación local usa el `debug.keystore` configurado por el proyecto; sirve para instalar y probar, pero no es una firma de producción para Play Store.
